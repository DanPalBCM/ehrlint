# LK005 — `split_overlap`

**Subject ids present in more than one split.**

| | |
| --- | --- |
| default severity | `error` |
| injector | `ehrlint.inject.inject_lk005` |

## Why this matters

The same patient in train and test means the test metric is partly measuring memorization. In EHR data this happens easily: splitting on encounters, admissions, or rows rather than on people puts one patient's records on both sides.

## What it looks like in practice

A split taken over rows rather than patients, or a re-split after a merge that reintroduced patients already in the training set.

## The query it runs

```sql
SELECT subject_id, COUNT(DISTINCT split) AS n_splits
FROM subject_splits GROUP BY subject_id HAVING n_splits > 1
```
