# LK008 — `encounter_group`

**A group (encounter, provider) straddling two splits.**

| | |
| --- | --- |
| default severity | `error` |
| injector | `ehrlint.inject.inject_lk008` |

## Why this matters

Records from one encounter share a clinician, a note template, and a coding pattern. When the same group appears in train and test, the model can recognize the group rather than the clinical signal -- the same failure as subject overlap, one level up.

## What it looks like in practice

Two admissions of the same patient under different subject ids landing in different splits, or several patients from one clinic visit sharing an encounter identifier.

## The query it runs

```sql
SELECT encounter_id, COUNT(DISTINCT split) AS n_splits
FROM events e JOIN subject_splits s USING (subject_id)
WHERE encounter_id IS NOT NULL
GROUP BY encounter_id HAVING n_splits > 1
```

## What to do about it

Group the split by the encounter or provider identifier, not only by subject.
